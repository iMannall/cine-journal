# Cine Journal

A personal cinematic journal built with Python to track movies, TV shows, and anime.

## Features

- Add movies, TV shows, and anime to your library.
- Organize titles by watch status.
- Rate titles from 0 to 10.
- Mark titles as favorites.
- Search your personal library.
- Remove titles from your collection.
- Save library data locally using JSON.

## Technologies

- Python
- JSON

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python3 main.py
```

## Project Purpose

Cine Journal is a personal project created to practice Python programming, file handling, and data management while building a useful tool for organizing entertainment.
